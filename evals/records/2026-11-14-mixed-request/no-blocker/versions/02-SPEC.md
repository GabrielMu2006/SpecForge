## 目标与范围

面向活动组织者，将内存中的报名姓名清理为可用于统计的名单，再按同名统计人数。核心例子：`[" Amy ", "  ", "BO", "Amy"]` 清洗后为 `["Amy", "BO", "Amy"]`，后续计数为 `{"Amy": 2, "BO": 1}`。同名报名仍保留；清洗不承担去重或身份识别。

V1 包含 `clean.py` 的 `clean_names(lines)` 和 `counts.py` 的 `count_names(names)`。仅使用现有 Python，无外部依赖、文件读写、网络、界面、持久化或额外入口。V2 暂无承诺，待 V1 使用反馈后再议。

## 使用流程与数据

调用方提供一组字符串 → 调用 `clean_names(lines)` → 获得新的普通列表 → 将结果交给 `count_names(names)` → 获得普通字典。空输入经过两步分别得到 `[]` 和 `{}`。

数据只在调用方内存中传递，不新增存储、共享或权限机制。姓名作为字符串处理，不判断是否为真实姓名。输入内容由调用方负责；非字符串元素及不符合约定的输入不在 V1 合约内，不另行承诺错误类型。

## 需求与验收

### R-001 — 清洗名单（V1；本轮实现）

对输入中每个字符串调用 Python 无参数 `str.strip()`，丢弃结果为空字符串的项；保留其余项原始顺序、大小写与重复项。只去掉两端空白，内部空白不变。返回新的普通 `list`，不修改原输入。空输入和全空白输入均返回 `[]`。

验收（逐项断言结果、返回类型及输入未改变）：

- `[" Amy ", "  ", "BO", "Amy"]` → `["Amy", "BO", "Amy"]`。
- `[]` → `[]`；`["", " \t\n", "\u3000"]` → `[]`。
- `["\tAmy\n", "amy", " A  B ", "Amy"]` → `["Amy", "amy", "A  B", "Amy"]`。
- 输入列表保持原值；即便无需清洗，返回列表也不是输入本身。
- 字符串元组等可迭代输入同样返回普通列表，不要求输入具有列表方法。

### R-002 — 同名计数（V1；后续实现）

`count_names(names)` 接收清洗结果，按完整字符串区分大小写计数，返回普通 `dict`。键按姓名首次出现的顺序排列，值为出现次数；不改变输入，不再次清洗或去重。空列表返回 `{}`。

验收：

- `["Amy", "BO", "Amy"]` → `{"Amy": 2, "BO": 1}`，键顺序为 `["Amy", "BO"]`。
- `["Amy", "amy", "Amy"]` → `{"Amy": 2, "amy": 1}`。
- `[]` → `{}`，返回类型为普通字典，输入保持不变。
- 联合流程：R-001 首个例子的清洗结果交给计数，得到 `{"Amy": 2, "BO": 1}`；全空白名单经过两步得到 `{}`。
