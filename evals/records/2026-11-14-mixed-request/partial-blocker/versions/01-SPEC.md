## 用户、目标与范围

面向活动组织者，将原始报名字符串清洗成可统计、可交给合作方导入的名单。代表场景：`[" Amy ", "  ", "BO", "Amy"]` 清洗为 `["Amy", "BO", "Amy"]`，同名计数为 `{"Amy": 2, "BO": 1}`，导出保持三条记录。不能通过去重、改大小写或猜测表头来“修正”数据；错误表头会被合作方拒收。

V1 包含清洗、区分大小写的同名计数、单列 CSV 文本导出。仅使用现有 Python 和标准库，无文件读写、网络、界面或外部依赖。V2 未承诺，待 V1 反馈后再讨论。

## 调用流程与数据

调用方提供字符串集合 → `clean_names(lines)` 返回新的普通列表 → 将该列表交给 `count_names(names)` 或 `export_names(names)`。后两者接收已清洗的名单，不再清洗或去重。输入字符串以外的值不属于本次输入契约，不新增类型转换或校验规则。

数据仅为调用方提供的内存中姓名；由调用方控制传入与返回数据，不新增存储、账户或共享权限。空输入贯穿流程应保留为空名单，计数为空字典，CSV 仅有已确认的表头。

## 需求与验收

### R-001 — 清洗名单（V1，可独立实施）

`clean.py` 的 `clean_names(lines)` 对每个字符串调用 Python `str.strip()`，去掉结果为空的项；保留顺序、大小写和重复项。返回新建的普通 `list`，不修改原输入。

验收：

- `[" Amy ", "  ", "BO", "Amy"]` → `["Amy", "BO", "Amy"]`。
- `[]` 和全空白字符串列表 → `[]`。
- 制表符、换行及 Unicode 空白遵循 `str.strip()`；内部空白保留，例如 `" A B "` → `"A B"`。
- 验证原输入内容未改变，返回类型恰为 `list`，返回对象独立于输入。

### R-002 — 同名计数（V1，本轮仅规格）

`counts.py` 的 `count_names(names)` 对已清洗名单区分大小写计数，返回字典，键按首次出现顺序排列。

验收：`["Amy", "BO", "Amy", "amy"]` → `{"Amy": 2, "BO": 1, "amy": 1}`，键顺序为 `Amy, BO, amy`；`[]` → `{}`。

### R-003 — 合作方 CSV 导出（V1，阻塞）

`export.py` 的 `export_names(names)` 返回带表头的 CSV 字符串：单列，一名一条记录，保持清洗名单的顺序、大小写和重复项，使用标准 CSV 转义与 LF 记录换行。空名单只返回表头记录。姓名中的逗号、双引号或换行应使用标准 CSV 引号规则表达，不能直接拼接字符串。

唯一表头必须严格使用合作方确认的 `name` 或 `full_name`，当前两者均未选定。不得添加默认值、额外参数、占位表头或替合作方代选。

确认后验收：令 H 为已确认表头，空名单输出 `H + "\n"`；普通名单输出 `H + "\nAmy\nBO\nAmy\n"`；含逗号、引号、内嵌换行的姓名经标准库 CSV 读取后应精确还原成单列原名单。记录分隔符为 LF；内嵌字符按输入保留。
