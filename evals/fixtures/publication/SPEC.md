# 纸报编辑游戏

Status: Draft
Current assignment: specification revision only

玩家调查线索、选择措辞并出版报纸。单人本地游戏，稿件可以在证据尚不充分时刊发，调查可以跨期。没有真实性分数；玩家只读已知材料。

### R-003 — 调查

指派记者消耗 250 单位预算，记者在调查期间不能接受其他任务。经过一期后获得新材料。不能承担费用时不启动。

### R-004 — 刊发

允许选择尚在调查的线索刊发，之后仍可对该事件写追踪报道。版面不足时不能出版；预览展示本期成本和收入预测。空版可以按少报规则出刊。

待定：没有规定刊发是否结束已支付费用的调查，以及相关提示。尚未定义普通出刊和少报预览与实际结算的关系。
