# Raw behavioral inputs

These are synthetic inputs, kept separate from the expectations in [the evaluation plan](../README.md). They are not generated outputs, actual user transcripts, or proof of model performance. Some intentionally contain missing decisions or outdated design states.

Copy only a case's fixture directory into an isolated workspace. Give the evaluator the case's user prompt and the complete runtime skill, without its expected outcome. Do not copy this README or the assessment criteria into the evaluator's context. Existing complete examples remain useful for E-03/E-04; E-05 and E-10 now have fixed inputs rather than manual edits.
