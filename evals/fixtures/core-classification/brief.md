# 本机资料归类工具：已选条件

这是合成的产品输入，不是已有最终规格或评判标准。

面向独立创作者，在 macOS 本机整理中英混合的草稿。最重要的结果是发现哪些内容属于同一个项目，系统建议、用户确认。措辞不同的相关内容也要能发现；同样使用“模型”这个词的无关文章不应因此混成一个项目。相似的文章不一定有真实的版本继承关系。

用户主动加入 TXT、Markdown、可选中文字的 PDF、公开网页和公开 GitHub 仓库文件。不扫描设备。仓库先列文件，由用户勾选。原文件不改，外部来源保留只读快照。支持项目状态、草稿版本和 macOS 桌面组件。

本机归类必须在完全断网、没有 API Key 时成立。DeepSeek 是可选增强，默认关闭，用户提供 Key。无需账号、云同步和团队功能。

目前没有代表性草稿集、质量基线或经采纳的数字门槛；也未验证可分发的本机语义方案。可以提出方案，但不能把这些说成已测得。
